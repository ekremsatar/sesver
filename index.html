GitHub Pages ile yayına alalım. Adım adım gidiyoruz: **1. Adım — Repo oluştur** - [github.com](https://github.com) → sağ üstte **+** işareti → **New repository** - Repository name: `sesver` (istersen farklı bir isim de olur) - **Public** seçili olsun - "Add a README file" kutusunu işaretle - **Create repository** butonuna bas **2. Adım — Dosyayı yükle** Önce dosyayı sana `index.html` adıyla hazırlıyorum, çünkü GitHub Pages siteyi otomatik olarak bu isimdeki dosyadan açar. Bu `index.html` dosyasını telefonuna indir. **Sonra repo sayfasında:** - **Add file** → **Upload files** - İndirdiğin `index.html` dosyasını seç ve yükle - Altta **Commit changes** butonuna bas **3. Adım — Pages'i aç** - Repo içinde **Settings** sekmesi → sol menüde **Pages** - "Branch" kısmından **main** ve **/ (root)** seç → **Save** - 1-2 dakika bekle, site şu adreste yayına girecek: `https://ekremsatar.github.io/sesver/` 1. adımı tamamlayıp repo oluşturduğunda haber ver, birlikte devam edelim.
